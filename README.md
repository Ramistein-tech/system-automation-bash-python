# System Automation Scripts (Bash & Python)

![Linux](https://img.shields.io/badge/Linux-FCC624?style=for-the-badge&logo=linux&logoColor=black)
![Bash](https://img.shields.io/badge/GNU_Bash-4EAA25?style=for-the-badge&logo=GNU%20Bash&logoColor=white)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

Automated system administration tools for Linux (Arch/Manjaro) and Windows environments, covering health checks, disk usage monitoring, and system log parsing.

---

## 🚀 Features

* **Hardware & Resource Monitoring:** Diagnostics for CPU load, RAM allocation, and disk partition integrity.
* **Network Audit Utility:** Validates local IP configurations, interface stability, and ping statistics.
* **Log Parser:** Parses system log files for critical error signatures.
